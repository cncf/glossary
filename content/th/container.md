Container คือโพรเซสที่กำลังทำงานอยู่ ซึ่งระบบปฏิบัติการของคอมพิวเตอร์เป็นผู้จัดการและควบคุมข้อจำกัดด้านทรัพยากรและความสามารถในการเข้าถึงทรัพยากรต่าง ๆ ไฟล์ที่โพรเซสภายใน Container สามารถเข้าถึงได้จะถูกรวมไว้ใน Container Image
Container หลายตัวสามารถทำงานอยู่บนเครื่องคอมพิวเตอร์เครื่องเดียวกันได้ โดยทั่วไป ระบบปฏิบัติการจะป้องกันไม่ให้โพรเซสของ Container แต่ละตัวติดต่อสื่อสารกันโดยตรง

## ปัญหาที่ Container ช่วยแก้

ก่อนที่จะมี Container การเรียกใช้แอปพลิเคชันแต่ละตัวจำเป็นต้องใช้เครื่องคอมพิวเตอร์แยกกัน โดยคอมพิวเตอร์แต่ละเครื่องจะต้องมีระบบปฏิบัติการเป็นของตัวเอง ซึ่งต้องใช้ทรัพยากรทั้ง CPU หน่วยความจำ และพื้นที่จัดเก็บข้อมูล เพียงเพื่อให้แอปพลิเคชันหนึ่งตัวทำงานได้
นอกจากนี้ การดูแลรักษา การอัปเกรด และการเริ่มต้นระบบปฏิบัติการยังเป็นงานซ้ำซากที่ต้องใช้เวลาและความพยายามอย่างมากอีกด้วย

## Container ช่วยได้อย่างไร

Container ใช้ระบบปฏิบัติการและทรัพยากรของเครื่องร่วมกัน ช่วยลดภาระการใช้ทรัพยากรที่เกิดจากระบบปฏิบัติการ และทำให้สามารถใช้ประโยชน์จากเครื่องคอมพิวเตอร์จริงได้อย่างมีประสิทธิภาพมากขึ้น
ความสามารถนี้เกิดขึ้นได้ก็เพราะโดยทั่วไป ระบบปฏิบัติการจะจำกัดไม่ให้โพรเซส Container แต่ละตัวติดต่อสื่อสารกันโดยตรง ส่งผลให้สามารถเรียกใช้แอปพลิเคชันจำนวนมากขึ้นบนเครื่องคอมพิวเตอร์จริงเพียงเครื่องเดียวได้

อย่างไรก็ตาม Container ก็มีข้อจำกัดเช่นกัน เนื่องจาก Container ใช้ระบบปฏิบัติการร่วมกัน โพรเซสภายใน Container จึงอาจมีความปลอดภัยน้อยกว่าทางเลือกอื่น ๆ นอกจากนี้ ยังจำเป็นต้องกำหนดขีดจำกัดการใช้ทรัพยากรที่ใช้ร่วมกันด้วย ผู้ดูแลระบบจึงต้องกำหนดและควบคุมการใช้หน่วยความจำและ CPU เพื่อรับประกันทรัพยากรที่จำเป็น และป้องกันไม่ให้แอปพลิเคชันอื่นมีประสิทธิภาพลดลง
