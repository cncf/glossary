# อภิธานศัพท์ Cloud Native

อภิธานศัพท์ Cloud Native มุ่งทำให้โลกของ cloud native ซึ่งขึ้นชื่อเรื่องความซับซ้อนเข้าใจได้ง่ายขึ้น
ไม่เพียงสำหรับผู้เชี่ยวชาญด้านเทคนิค แต่รวมถึงผู้ที่ทำงานด้านธุรกิจด้วย
เพื่อให้บรรลุเป้าหมายนี้ เราเน้นความเรียบง่าย เช่น ใช้ภาษาที่เข้าใจง่าย หลีกเลี่ยงศัพท์การตลาด ยกตัวอย่างที่ทุกคนที่ใช้เทคโนโลยีเชื่อมโยงได้ และตัดรายละเอียดที่ไม่จำเป็นออก
อภิธานศัพท์นี้เป็นโครงการที่นำโดย Business Value Subcommittee (BVS) ของ CNCF

## การมีส่วนร่วม

ทุกคนได้รับเชิญให้เสนอการเปลี่ยนแปลง เพิ่มเติม และปรับปรุงอภิธานศัพท์ Cloud Native
เราใช้กระบวนการพัฒนาโดยชุมชนภายใต้การดูแลของ CNCF เพื่อพัฒนาและปรับปรุงคลังคำศัพท์ร่วมนี้
อภิธานศัพท์นี้เป็นแพลตฟอร์มที่เป็นกลางต่อผู้ให้บริการ สำหรับจัดระเบียบคำศัพท์ร่วมของเทคโนโลยี cloud native
เรายินดีรับการมีส่วนร่วมจากทุกคนที่ปฏิบัติตามวัตถุประสงค์และกฎบัตรของโครงการ

ทุกคนที่ต้องการมีส่วนร่วมสามารถสร้าง GitHub issue หรือ pull request ได้
โปรดปฏิบัติตาม[คู่มือรูปแบบเอกสาร](/style-guide/) อ่าน[แนวทางการมีส่วนร่วม](/contribute/) เข้าร่วม [CNCF Slack](https://slack.cncf.io) และเข้าร่วมช่องห้องสนทนา [#glossary](https://cloud-native.slack.com/archives/C02TX20MQBB)
นอกจากนี้ยังมีช่องห้องสนทนา [#glossary-localizations](https://cloud-native.slack.com/archives/C02N2RGFXDF) สำหรับผู้ที่ต้องการช่วยแปลอภิธานศัพท์เป็นภาษาท้องถิ่น
